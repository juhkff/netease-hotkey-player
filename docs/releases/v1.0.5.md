## 更新内容

- Windows x64 免安装包自带独立运行时，无需安装 Node.js 或修改 PATH。
- 修复播放服务启动失败后“没有与此对象关联的进程”异常，并支持失败恢复。
- 支持 Microsoft Store 版网易云的识别和带调试参数启动；保留普通 Windows 安装版启动逻辑。
- 播放键和复位键只监听、不拦截，保留游戏和其他程序中的原按键功能；长按只触发一次。
- 修复 Oemplus 等符号键、小键盘按键，以及录制名称无法解析的问题。
- 修复中文搜索关键词编码和搜索结果列表解析，连续搜索只显示最后一次请求的结果。
- 复用已显示的歌曲行，缓存歌曲信息，减少重复搜索和固定等待。
- 新增 GitHub Actions：提交和 PR 自动检查；推送版本标签后自动测试、打包并发布 Release。

## 下载和使用

下载 **netease-hotkey-player-v1.0.5-win-x64.zip**，完整解压后运行 **NcmHotkey.exe**。保留旁边的 `runtime`、`lib` 和 `worker.mjs`。可用 **SHA256SUMS-v1.0.5.txt** 校验压缩包。

首次使用需从托盘完全退出网易云，再在工具中点击“启动网易云”，启用本地控制端口。添加歌曲和热键后即可后台控制播放。升级时先退出旧工具，替换程序文件并保留自己的 `config.json`。

当前实测为 Microsoft Store 版网易云 3.1.23；普通安装版及其他版本是否适用，取决于其调试端口和页面结构。切歌仍受网络取流和客户端缓冲影响；歌曲能否播放取决于账号权限和客户端实际可播状态。

安装包不包含音乐文件或个人热键配置。
