## 更新内容

- 新增实验功能“游戏事件”：按游戏、事件、角色槽位配置自动播放歌曲，支持歌曲起点和触发延迟。当前适配《罪恶装备·奋战》凯发动龙装。
- 1P、2P 可分别或同时勾选；同一规则在延迟窗口内的双方事件合并触发，重叠规则会提示冲突。事件与热键共用播放、复位服务。
- 游戏事件页面的规则表下方显示实时游戏状态；编辑期间继续显示已保存规则的状态，并暂停自动切歌。主页面入口与其他按钮排在同一行。
- 修复复位时原曲不在队列、或“上一首”未返回原曲时的处理，支持重新加载原曲并恢复位置、队列和播放状态。
- 播放与复位增加超时和失败恢复，避免长期停留在“正在播放”或“正在复位”。复位可中断尚未完成的播放请求；中断点保留在当前播放服务中供重试。
- 减少切歌前的额外查询与固定等待，确认暂停和进度定位后立即继续播放，并保留真实进度验证。修复搜索页标题与歌曲列表不一致时反复搜索旧列表的问题。
- 增加事件调度、界面、播放进度及工作进程恢复检查，随 GitHub Actions 自动构建发布。

## 下载和升级

下载 **netease-hotkey-player-v1.0.6-win-x64.zip**，完整解压后运行 **NcmHotkey.exe**。程序包自带运行时，无需安装 Node.js。可用 **SHA256SUMS-v1.0.6.txt** 校验压缩包。

升级前退出旧工具，替换程序文件并保留自己的 `config.json`。新增加的游戏事件监听默认关闭；已有实验配置会保留。首次连接网易云时，先从托盘完全退出客户端，再用本工具的“启动网易云”打开。

## 游戏事件的验证范围

训练场已实测龙装触发切歌，并检查了连续两轮播放与复位。联网对战、回放及观战仍待验证。当前 GGST 适配仅接受 Steam build 24797162 对应的已验证 EXE，其他版本会停止读取。

监听角色按开局槽位选择，尚未自动识别联网时自己操控的一方；不包含败北停歌、游戏 BGM 降音量或淡入。原游戏声音 Mod 不会自动停用，同时使用可能叠加。设定的延迟之外，网易云搜索、网络和客户端缓冲仍会增加耗时。

发布包不包含音乐文件、游戏文件或个人配置。完整说明见仓库 README。
